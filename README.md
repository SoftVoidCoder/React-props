# React Props

Учебный проект на React + Vite.

Реализовано:

- компонент `UserCard`, который получает `name` и `age` через пропсы;
- 3 разные карточки пользователей;
- деструктуризация пропсов в `UserCard({ name, age })`;
- компонент `Card`, который принимает `children`;
- компонент `Button`, который принимает `onClick` и текст через `children`;
- две кнопки с разными обработчиками: `alert` и `console.log`.

Запуск:

```bash
npm install
npm run dev
```
